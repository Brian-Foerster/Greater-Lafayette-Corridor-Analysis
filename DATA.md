# Data Acquisition Guide

## Tracked in Git (`data/raw/`)

These files are committed to the repository and require no additional download:

| File | Description |
|------|-------------|
| `parcels.geojson` | Tippecanoe County parcel boundaries with assessed values (CurLandAV/CurImpAV/CurTotAV) |
| `zones.geojson` | 1,632 zone polygons for spatial aggregation |
| `roads.geojson` | Road network for corridor routing |
| `cities.geojson` | Municipal boundaries |
| `county_boundary.geojson` | County boundary |
| `highways.geojson` | Highway network |
| `tif.geojson` | Existing TIF district boundaries |
| `improvements_av.geojson` | Improvement assessed values |
| `land_av.geojson` | Land assessed values |
| `total_av.geojson` | Total assessed values |
| `sales_2021–2025.geojson` | Annual property sales |
| `sample_zones.geojson` | Sample zone subset for testing |
| `zoning_density_estimates.csv` | Zoning FAR/density limits |
| `System Technology Parameters.csv` | APM/BRT technology cost parameters |
| `CityBus2025/` | Current GTFS feed + monthly ridership CSVs |
| `CityBusOld/` | Historical GTFS feed + route productivity data |
| `lehd/in_od_2022.csv.gz` | LODES origin-destination flows (2022) |
| `lehd/in_wac_2022.csv.gz` | LODES workplace area characteristics (2022) |
| `tl_2020_18_tabblock20/` | Census 2020 block boundaries (shapefile) |

## Must Be Downloaded

These files are gitignored due to size or licensing. Download before running.

### LODES 2023 (optional, improves job estimates)

Download from [LEHD](https://lehd.ces.census.gov/data/lodes/LODES8/):

```
data/raw/lehd/in_od_2023.csv.gz    # Origin-Destination (Indiana, 2023)
data/raw/lehd/in_wac_2023.csv.gz   # Workplace Area Characteristics (Indiana, 2023)
```

The model falls back to the tracked 2022 files if 2023 versions are absent.

### DEM (optional, improves grade penalty in corridor scoring)

Download the Tippecanoe County 10m DEM from
[USGS TNM](https://apps.nationalmap.gov/downloader/) (search for
"Tippecanoe County, IN", 1/3 arc-second DEM):

```
data/raw/dem_tippecanoe.tif         # ~408 MB
```

The corridor search runs without it but skips elevation-based grade penalties.

## Auto-Generated (`data/processed/`)

Everything in `data/processed/` is gitignored and regenerated by the pipeline.
Key generated files:

| File | Generated by |
|------|-------------|
| `parcels_enriched_final.geojson` | `src/ensure_enriched.py` (called automatically) |
| `parcels_enriched_final.parquet` | Parquet cache of the above |
| `osm_road_network.graphml` | `src/build_network.py` |
| `lafayette_road_network.pkl` | Cached road graph |
| `corridor_viewer.html` | Feedback loop / evaluation scripts |
| `decision_package/` | `scripts/generate_decision_package.py` |

Do not commit files from `data/processed/` — they are reproducible from raw
inputs.
